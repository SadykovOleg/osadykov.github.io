Файлы для сайта osadykov.ru

1. Замените текущий index.html файлом из этого архива.
2. Добавьте soglasie-pdn.md в корень Jekyll-репозитория GitHub Pages. Он создаёт страницу /soglasie-pdn/.
3. В index.html замените REPLACE_WITH_PAYMENT_OR_BOOKING_URL на вашу реальную ссылку записи/оплаты.

Важно: чекбокс блокирует переход к записи, пока пользователь его не отметит. Но текущий сайт статический: этот код сам по себе не сохраняет доказательство согласия на сервере и не отправляет отметку вместе с заявкой. Для надёжной фиксации нужен backend/сервис формы, который сохраняет текст/версию согласия, дату и время и связывает их с заявкой. Проверьте соответствие текста фактическим полям, целям, системам и срокам хранения до публикации.
