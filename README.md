# Никогда не поздно — Jekyll-лендинг

## Перед публикацией обязательно проверьте

1. **`_config.yml` → `offer.deadline_date`**: дата `16 сентября 2026` уже прошла на момент сборки этого шаблона. Замените на актуальную дату акции (или уберите блок `.deadline-box` в `index.html`, если хотите бессрочное предложение).
2. **`_config.yml` → `url` и `baseurl`**: заполните после создания репозитория на GitHub (см. инструкцию в чате).
3. **Бонусы**: сумма бонусов в тексте урока — 21 800 ₽ (4 позиции). В более ранней презентации PDF/PPTX фигурировала другая сумма — 25 800 ₽ с 5-й позицией («Как проверить брокера на скам»). Проверьте, какой вариант актуален, и поправьте `_data/bonuses.yml`.

## Структура

- `_config.yml` — все цифры оффера (цена, бонусы, дедлайн, контакты) в одном месте
- `_data/*.yml` — кейсы, бесплатные материалы, бонусы, возражения (редактируются без трогания HTML)
- `_layouts/default.html` — общий каркас страницы
- `index.html` — сама страница лендинга
- `assets/css/style.css`, `assets/js/main.js` — стили и аккордеон/чек-лист

## Локальный запуск (опционально)

```
bundle exec jekyll serve
```

Откроется на http://localhost:4000
